# Support

OutyDS is free and open-source software distributed under GNU GPL-3.0. Donations are voluntary and help support continued development. Support is provided on a best-effort basis, without guaranteed response times, fixes, updates or compatibility.

OutyDS is maintained by an individual, not a company.

## What to expect
- Support is **best effort**.
- There is **no guaranteed response time**.
- There is **no guarantee that a reported issue will be fixed**.
- Compatibility depends on the vehicle, the Android version, the phone and the available hardware (OBD adapter, car WiFi).
- Donations do not change any of this (see [DONATIONS.md](DONATIONS.md)).

## Before you ask
1. Read the [FAQ](FAQ.md).
2. Check the [Wiki](https://github.com/cangri-outy/Outy/wiki).
3. Search the existing [GitHub Issues](https://github.com/cangri-outy/Outy/issues).

## How to report a problem
Open a new issue on [GitHub Issues](https://github.com/cangri-outy/Outy/issues) and include:

- OutyDS version (Settings screen)
- Android version
- Phone model
- Vehicle model year
- Steps to reproduce the problem

## Before you publish logs or screenshots
Logs and CSV/JSON reports can contain your **VIN** and **GPS coordinates** (location track). Screenshots of the Remote settings screen can show the car's **WiFi name and password**. No code was found that writes the WiFi password into logs or reports. **Remove or crop all of this before posting**, and never post passwords or other secrets.

Security problems: see [SECURITY.md](SECURITY.md), do not post them publicly.
